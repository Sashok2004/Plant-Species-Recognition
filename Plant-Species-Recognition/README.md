# Crop and Weed Detection (Распознавание культур и сорняков)

Данный проект разработан в рамках практики по компьютерному зрению. Основная задача — автоматическое распознавание полезных сельскохозяйственных культур и сорняков на изображениях для нужд точного земледелия.

Проект использует современную архитектуру нейронных сетей **YOLOv8** (фреймворк `ultralytics`) и библиотеку **OpenCV** для обработки изображений. 

В качестве данных используется открытый набор данных **CropWeeds-YOLO** с платформы Kaggle. Нейросеть решает задачу детекции объектов (Object Detection), выделяя растения ограничивающими рамками (bounding boxes) и классифицируя их.

## Структура проекта
Репозиторий организован в соответствии со стандартами разработки:

- `dataset/` — конфигурация датасета (`dataset.yaml`) и примеры данных. *(Примечание: полная база изображений не загружена в GitHub из-за ограничений по размеру, инструкция по скачиванию ниже).*
- `src/` — исходный код проекта.
  - `train.py` — скрипт инициализации, настройки параметров и обучения модели.
  - `predict.py` — скрипт для тестирования обученной модели (инференс) с выводом результатов через OpenCV.
- `requirements.txt` — список необходимых Python-библиотек с указанием версий.
- `.gitignore` — файл исключений для предотвращения загрузки системных файлов и тяжелых весов моделей в репозиторий.

## Как развернуть и запустить проект локально

**1. Клонирование репозитория на ваш компьютер:**
\`\`\`bash
git clone https://github.com/Sashok2004/Plant-Species-Recognition.git
cd Plant-Species-Recognition
\`\`\`

**2. Создание и активация виртуального окружения:**
Рекомендуется использовать виртуальное окружение, чтобы избежать конфликта версий библиотек.
\`\`\`bash
# Создание окружения
python -m venv venv

# Активация для Windows:
venv\Scripts\activate
# Активация для Linux/MacOS:
source venv/bin/activate
\`\`\`

**3. Установка зависимостей:**
\`\`\`bash
pip install -r requirements.txt
\`\`\`

**4. Подготовка датасета:**
1. Скачайте датасет по ссылке: [CropWeeds-YOLO Dataset на Kaggle](https://www.kaggle.com/datasets/swish9/weeds-detection)
2. Распакуйте архив.
3. Поместите папки с изображениями и разметкой внутрь директории `dataset/`, чтобы структура соответствовала конфигурации в `dataset/dataset.yaml`.

**5. Запуск обучения (Тренировка модели):**
Для запуска процесса обучения выполните команду:
\`\`\`bash
python src/train.py
\`\`\`
*Результаты обучения, графики метрик и сохраненные веса модели (например, `best.pt`) автоматически сохранятся в папке `runs/detect/`.*

**6. Запуск проверки (Инференс):**
Для проверки работы модели на новых фотографиях откройте файл `src/predict.py`, укажите путь к тестовому изображению и запустите скрипт:
\`\`\`bash
python src/predict.py
\`\`\`
Откроется окно OpenCV с фотографией, на которой нейросеть выделит культуры и сорняки прямоугольниками.
